# 天气图表技能

## 描述
使用和风天气 API 生成广州逐小时气温预报折线图。图表包含平滑温度曲线 + 湿度曲线（双Y轴），图标密度按小时段自动递减（≤24h:12, ≤48h:6, ≤72h:4, ≤120h:3, 其余2个/天），x 轴刻度与图标对齐，深色主题。

## 触发条件
- 一般天气查询（"天气"、"温度"、"预报"）→ 执行逐小时图表 `chart.py`
- 降水相关查询（"下雨"、"降水"、"带伞"、"分钟预报"、"雷达"）→ 执行分钟降水图表 `minutely_chart.py`

## 逐小时天气图表

### 执行方式
```shell
python3 /AstrBot/data/skills/weather_chart/scripts/chart.py
```

### 参数
- `-H <int>` — 预报小时数（≤168 且必须为 12 的倍数，默认 48）
- `-L <区名>` — 指定区名，如 `番禺`、`天河`。不指定则用默认地点
- `-o /path/to/output.png` — 自定义输出路径

## 分钟降水预报图表

### 执行方式
```shell
python3 /AstrBot/data/skills/weather_chart/scripts/minutely_chart.py
```

### 参数
- `-L <区名>` — 指定区名，如 `番禺`、`天河`。不指定则用默认地点
- `-o /path/to/output.png` — 自定义输出路径

数据来源：和风天气 minutely/5m API，未来 2 小时每 5 分钟一个降水数据点，柱状图展示。
