# weekly_summary

当用户要求「总结/回顾某段时间的聊天内容」时触发此 Skill。

## 触发条件

用户消息包含以下任一模式：

- 「总结这周」「这周干了啥」「这周总结」「周报」「weekly summary」→ 周一起始
- 「总结上周」→ 上周一起始
- 「总结 XX→XX」「总结 X月X日」等含日期范围的表达 → 解析日期

**默认规则**：
- 「上周」→ `start = 上周一`，`end = 上周日`
- 「这周」→ `start = 本周一`，`end = 今天`
- 无日期且周日 → 等同于「这周」

## 执行步骤

### 第一步：运行 extract_chat.py

```bash
python3 /AstrBot/data/skills/weekly_summary/scripts/extract_chat.py \
  --user tool-nut --start YYYY-MM-DD --end YYYY-MM-DD \
  --out /tmp/week_raw.md
```

脚本只做一件事：从所有 `astrbot*.log` 中提取指定用户和时间范围的原始聊天记录，输出为 md 文件。

### 第二步：LLM 读取原始数据并总结

读取 `/tmp/week_raw.md`，按以下模板生成结构化总结。**不要发送原始聊天记录——只发送总结 md。**

### 第三步：发送总结

将总结写入 `/tmp/week_summary.md`，用 `send_message_to_user` 发送文件。

## 总结模板

```markdown
# 本周总结 (start → end)

---

## 做了什么

### 1. 话题名称 ⭐（可选：标注重点话题）

- **已完成**：xxx
- **关键决策**：xxx
- **未闭环**：xxx

### 2. 另一个话题

...

（按话题归类，不是按日期。同一话题跨多天应合并到一个条目下。最多 5~6 个话题。）

---

## 可以改进的

### 1. 改进点标题

一句话描述问题 + 具体建议。每条 2~3 句。

### 2. 另一个改进点

...

（最多 3~4 条。）

---

## 下一步

### 1. 下一步标题

具体可执行的动作。每条 1~2 句。

### 2. 另一个下一步

...

（最多 3~4 条。）
```

## 附加规则

- **日期标注**：每个话题条目下方用括号标注涉及的日期+周几，如「（7/24 周四）」或「（7/22 周二 ~ 7/24 周四）」
- **情绪总结**：如果某天对话密度/效率明显突出，在话题末尾加一行点评，如「本周最高效的一天是周四——FP-30X 从理论到导出全链路 3 小时闭环」
- **关联未闭环**：在「下一步」中优先列出之前总结标注过「未闭环」的项
- **文件清理**：总结发送后删除 `/tmp/week_raw.md`（原始数据太大不用留）
